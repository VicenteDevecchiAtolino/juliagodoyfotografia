# Júlia Godoy Fotografia — Da Câmera ao Negócio

Landing page do curso **Da Câmera ao Negócio: Fotografia, Técnica e Mercado** e do workshop **Fotografia Essencial**.

## Estrutura

```
index.html   → o site completo (HTML, CSS e JS num arquivo só)
fotos/       → fotos da Júlia (banner e retrato)
assets/      → logo e ícone (versões original e clara)
```

## Editar

- **Links de pagamento (Kiwify):** no final do `index.html`, no bloco `CHECKOUT`.
- **WhatsApp:** procure por `wa.me/5511978178806` no `index.html`.
- **Fotos:** substitua `fotos/julia-banner.jpg` e `fotos/julia-retrato.jpg` mantendo o nome (vertical 4:5, ~1200×1500 px).

## Publicar no GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
